# TRAINEDBY for Grok

Official Grok plugin for [TRAINEDBY](https://www.trainedby.fit).

This plugin attaches the hosted MCP server at `https://mcp.trainedby.fit/mcp`. You sign in with your TRAINEDBY coach account via Auth0 (`https://trainedby-mcp.us.auth0.com`). No API keys live in this plugin.

Docs: https://www.trainedby.fit/connect-ai

Network endpoints:

- `https://mcp.trainedby.fit/mcp`
- `https://trainedby-mcp.us.auth0.com`
