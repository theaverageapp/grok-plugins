# TRAINEDBY for Grok

Official Grok plugin for [TRAINEDBY](https://www.trainedby.fit).

This plugin attaches the hosted MCP server at `https://mcp.trainedby.fit/mcp`. You sign in with your TRAINEDBY coach account through OAuth at `https://mcp.trainedby.fit`, operated by TRAINEDBY FIT LTD. No API keys live in this plugin.

Docs: https://www.trainedby.fit/connect-ai

Network endpoints:

- `https://mcp.trainedby.fit/mcp`
- `https://mcp.trainedby.fit` (OAuth sign-in)
