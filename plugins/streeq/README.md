# STREEQ for Grok

Official Grok plugin for [STREEQ](https://streeq.app).

This plugin attaches the hosted MCP server at `https://mcp.streeq.app/streeq/mcp`. You sign in with your STREEQ account through OAuth at `https://mcp.trainedby.fit`, operated by TRAINEDBY FIT LTD. No API keys live in this plugin.

Docs: https://streeq.app/connect-ai

Network endpoints:

- `https://mcp.streeq.app/streeq/mcp`
- `https://mcp.trainedby.fit` (OAuth sign-in)
