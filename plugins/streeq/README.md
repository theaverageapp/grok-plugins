# STREEQ for Grok

Official Grok plugin for [STREEQ](https://streeq.app).

This plugin attaches the hosted MCP server at `https://mcp.streeq.app/streeq/mcp`. You sign in with your STREEQ account via Auth0 (`https://trainedby-mcp.us.auth0.com`). No API keys live in this plugin.

Docs: https://streeq.app/connect-ai

Network endpoints:

- `https://mcp.streeq.app/streeq/mcp`
- `https://trainedby-mcp.us.auth0.com`
